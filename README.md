# PRO-CHISTKA Portfolio MVP v0.1

Статический виджет портфолио для GitHub Pages и Tilda. Сервер, база данных и авторизация не используются.

## Что уже работает

- карточки объектов из статического файла данных;
- фильтрация по типу уборки;
- интерактивное сравнение фотографий «до/после»;
- подробное модальное окно объекта;
- галерея;
- подготовленная поддержка iframe-видео и MP4;
- кнопки заявки через `#popup:prolead`;
- цели Яндекс.Метрики при указании `data-metrika-id`;
- адаптив для планшета и телефона;
- защита стилей префиксом `pc-`.

## Файлы

- `index.html` — локальная демонстрация;
- `widget.js` — логика публичного виджета;
- `widget.css` — стили;
- `data/works.json` — исходные данные карточек;
- `data/works-data.js` — те же данные в JS-формате для надёжного подключения из Tilda без зависимости от CORS;
- `media/` — тестовые изображения;
- `tilda-embed.html` — шаблон кода для блока T123.

## Локальный запуск

Откройте папку через любой статический сервер. Например:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий.
2. Загрузите содержимое этой папки в корень репозитория.
3. В GitHub откройте `Settings → Pages`.
4. Выберите `Deploy from a branch`, ветку `main`, папку `/root`.
5. После публикации замените `USERNAME` и `REPOSITORY` в `tilda-embed.html`.
6. Вставьте полученный код в Tilda T123 и опубликуйте страницу.

## Как изменить карточки сейчас

Редактируйте `data/works.json`, затем обновляйте `data/works-data.js`. В следующем этапе будет создан редактор, который сделает это автоматически и экспортирует готовый ZIP.

## Структура видео

В объект можно добавить:

```json
"video": {
  "type": "iframe",
  "url": "https://.../embed/...",
  "poster": "./media/poster.webp"
}
```

или MP4:

```json
"video": {
  "type": "file",
  "url": "./media/video.mp4",
  "poster": "./media/poster.webp"
}
```
